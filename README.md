# 株式会社アース 入居者管理システム (User Management System)

株式会社アース（EARTH CARE GROUP）公式Webアプリケーション・デザインシステムに完全準拠した、**入居者管理およびExcel（.xls / .xlsx / .csv）取り込みシステム**です。

---

## 🌟 主な特徴・機能

1. **.xls / .xlsx / .csv ファイルのドラッグ＆ドロップ取り込み**
   - 介護ソフトやExcel台帳から出力したファイルをそのままブラウザにドラッグ＆ドロップするだけで、列名を自動認識して解析・反映。
   - インポート前に「新規入居」「更新・変更」「退去（空室化）」の差分を色分けプレビューし、誤った上書きを防止。

2. **業務に合わせた多彩なビュー（タブ切替）**
   - 📋 **全体管理表**: 部屋番号、氏名、介護度、年齢、生年月日、訪問医、歯科、福祉用具、食事形態、エアコン利用等を一覧表示。検索・絞り込み・ソート対応。
   - 🏢 **居室フロアマップ (2F / 3F)**: 建物の間取りに合わせた見取り図表示。空室状況や各居室のケア状況が一目で把握可能。
   - 🍚 **食事・厨房指示一覧**: 主食・副食形態、とろみ有無、早出し対象者の自動集計と配膳チェックリスト。
   - 🏥 **訪問医・福祉用具**: 提携クリニック別の受診者リスト（上限受診枠アラート機能付き）および福祉用具の管理。
   - 🕒 **異動・退去履歴**: 入院・逝去・特養等への転出ログを自動記録・管理。

3. **アース公式デザインシステム（Earth Design System）準拠**
   - アースグリーン（`#247d1b`）、アイボリー（`#f7f2e7`）、淡緑（`#e2f0df`）を基調とした清潔感と温かみのあるデザイン。
   - 見出し（Shippori Mincho）、英数字（Manrope）、本文（Noto Sans JP）の美しいタイポグラフィ。
   - 公式ロゴマークおよび起動スプラッシュスクリーン。

4. **帳票印刷 & エクスポート**
   - 🖨️ **A4印刷最適化**: ボタンやUIを隠し、現場配布用・配膳用のクリーンな帳票レイアウトを出力。
   - 📥 **Excel (.xlsx) / CSV出力**: 最新の管理表や食事指示をワンクリックでExcelファイルとしてダウンロード。

5. **高セキュリティ・オフライン動作**
   - クライアント側（ブラウザ内）で完全にファイル解析・データ保持（LocalStorage）を行うため、**入居者の個人情報が外部サーバーへ送信されることなく安全**です。

---

## 🚀 起動方法

特別なサーバー設定やインストールは不要です。

1. 本リポジトリ内の `index.html` を任意のブラウザ（Google Chrome, Microsoft Edge, Safari等）で開きます。
2. 事務所のPCはもちろん、iPadやタブレット端末でもそのまま快適にご利用いただけます。
